  The model is inverted for your domain — normal shopping looks more anomalous
  than shoplifting. This is because STG-NF was trained on ShanghaiTech campus 
  scenes (running, fighting, cycling) not retail environments. A single
  threshold won't fix this — you need calibration data.

  ---
  How to properly calibrate for wild retail videos

  Step 1 — Build a labeled calibration set

  Record/collect ~20-30 short clips, labeled:
  - normal/ — browsing, picking items off shelves, paying, walking
  - shoplifting/ — concealing items, pocket stuffing, bag stuffing, quick grabs

  Step 2 — Run inference on all clips, collect scores

  # Run each video, saves scores JSON automatically

    .venv/bin/python video_inference_pipeline.py \

  done

  Step 3 — Find the optimal threshold

  Run this analysis script after collecting scores:

  import json, glob, numpy as np
  from sklearn.metrics import roc_curve, roc_auc_score, f1_score

  all_scores = []
  all_labels = []  # 1 = shoplifting, 0 = normal

  for path in glob.glob("inference_outputs/calibration/**/*scores.json",
  recursive=True):
      with open(path) as f:
          data = json.load(f)

      # Determine label from path
      label = 1 if "shoplifting" in path.lower() else 0

      # Use clip-level max-score aggregation (most anomalous frame wins)
      scores = [r["score"] for r in data["results"] if r["score"] is not None]
      if not scores:
          continue

      # For clip-level classification: use the min score (most anomalous)
      clip_score = min(scores)
      all_scores.append(clip_score)
      all_labels.append(label)

  all_scores = np.array(all_scores)
  all_labels = np.array(all_labels)

  # Find threshold that maximizes F1
  thresholds = np.linspace(all_scores.min(), all_scores.max(), 200)
  best_f1, best_thresh = 0, 0
  for th in thresholds:
      preds = (all_scores <= th).astype(int)  # alert = score <= threshold
      tp = ((preds == 1) & (all_labels == 1)).sum()
      fp = ((preds == 1) & (all_labels == 0)).sum()
      fn = ((preds == 0) & (all_labels == 1)).sum()
      if tp + fp + fn == 0:
          continue
      f1 = 2*tp / (2*tp + fp + fn)
      if f1 > best_f1:
          best_f1, best_thresh = f1, th

  print(f"Optimal threshold: {best_thresh:.4f}  (F1={best_f1:.3f})")

  # Also check FPR at this threshold
  fpr, tpr, roc_thresh = roc_curve(all_labels, -all_scores)  # negate: 
  lower=more anomalous
  auc = roc_auc_score(all_labels, -all_scores)
  print(f"AUC-ROC on your data: {auc:.3f}")

  # Find threshold for FPR < 10% 
  target_fpr = 0.10
  idx = np.searchsorted(fpr, target_fpr)
  low_fpr_thresh = -roc_thresh[idx]
  print(f"Threshold for FPR<{target_fpr*100:.0f}%: {low_fpr_thresh:.4f}  
  (TPR={tpr[idx]:.3f})")

  Step 4 — Adaptive / per-scene baseline (more robust)

  Rather than a fixed global threshold, normalize scores against that person's
  recent history:

  # Instead of: alert = score <= -1.2
  # Use: alert = score <= (baseline - k * std)

  from collections import deque

  class AdaptiveThreshold:
      def __init__(self, window=150, k=2.0):
          self.history = deque(maxlen=window)  # ~5 sec at 30fps
          self.k = k

      def is_alert(self, score):
          self.history.append(score)
          if len(self.history) < 30:
              return False  # not enough data yet
          mean = np.mean(self.history)
          std = np.std(self.history)
          return score <= (mean - self.k * std)

  This is more robust for wild videos because it adapts to whatever "normal"
  looks like in your specific store/camera/lighting.

  Root cause: consider retraining on retail data

  The deeper fix is that the ShanghaiTech weights don't match your domain. Once
  you've built your calibration set, the right next step is training (or
  fine-tuning) on it — even 30-50 labeled clips would help significantly. That's
   what the --mode train-scratch workflow is for.
