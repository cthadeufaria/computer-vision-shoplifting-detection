# STG-NF Artifacts

This directory stores local STG-NF runtime data that does not belong in the
forked `stg_nf_official/` module.

Keep generated files here, for example:

- `exports/`
- `logs/`
- `tb_eval_runs/`
- `inference_outputs/`
- `data/stg_nf_data.zip`

The contents of this directory are ignored by git in the parent project, except
for this README.
